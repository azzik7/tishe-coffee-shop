# тише, интернет-магазин кофе

## Локальный запуск

```powershell
npm start
```

Сайт: `http://127.0.0.1:4173/`

Админка: `http://127.0.0.1:4173/admin.html`

В режиме разработки создаётся локальный администратор:

- email: `admin@tishe.local`
- пароль: `ChangeMe-2026!`

## Перед публикацией

Задайте переменные из `.env.example` в панели хостинга. Не публикуйте локальный файл `data/store.json`. В production сервер не создаёт стандартного администратора без `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

Сейчас `PAYMENT_MODE=test`. После выбора платёжного сервиса тестовый обработчик нужно заменить созданием платежа и проверенным webhook этого сервиса. До этого реальные деньги сайт не принимает.

JSON-хранилище подходит для первого запуска и небольшого объёма заказов. Перед публичной рекламой магазина его следует заменить PostgreSQL и настроить резервные копии.

## Что происходит после заказа

1. Backend проверяет товар, цену, остаток и данные клиента.
2. Товар резервируется на 30 минут, заказ сохраняется в `data/store.json`.
3. После подтверждения оплаты заказ получает статус `confirmed` и появляется в админке.
4. Если настроен Telegram, кофейня получает уведомление об оплаченном заказе.
5. Сотрудник меняет статусы: принят, готовится, готов, выполнен.
6. Клиент видит эти изменения на персональной странице `order.html`.
7. При отмене или истечении неоплаченного резерва товар возвращается в остаток.

Админка является главным источником рабочих данных. Telegram и будущие email-уведомления только дублируют события.
